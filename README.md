# CogniPilot Enhancement Proposals (CEPs)

This repository contains CogniPilot Enhancement Proposals (CEPs), which are design documents providing information to the CogniPilot community, or describing new features, architectural changes, or processes for CogniPilot and its ecosystem.

CEPs are inspired by [Python Enhancement Proposals (PEPs)](https://peps.python.org/) and [ROS Enhancement Proposals (REPs)](https://ros.org/reps/rep-0000.html).

## What is a CEP?

A CEP is a design document that:

- Describes a new feature or significant change for CogniPilot
- Documents design decisions and rationale
- Provides a concise technical specification
- Builds consensus within the community

## Contributing

Before submitting a CEP, please read [CEP-0001](CEP-0001.md) which describes the CEP process and guidelines.

To propose a new CEP:

1. Fork this repository
2. Create your CEP using the template format described in CEP-0001
3. Submit a pull request
4. Engage in discussion and iterate based on feedback

## CEP Types

- **Standards Track**: Describes new features or implementation changes
- **Informational**: Provides design guidelines or general information
- **Process**: Describes procedures and workflows for CogniPilot development
